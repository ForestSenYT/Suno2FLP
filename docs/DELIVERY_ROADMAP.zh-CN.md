# 可交付版本路线与持续目标看板

目标：用户在 Windows GUI 中输入一首 Suno 音频，自动得到可编辑音符、分轨、速度／
结构、可发声音源的新 FLP、重建试听和可追溯质量报告。音色允许近似，发布须质量
达标。完整范围与数值标准以[产品设计](superpowers/specs/2026-10-16-deliverable-audio-to-flp-design.zh-CN.md)
为准；当前目标保持 active，以下未完成项不能因 CI 通过而勾选。

## 完成定义

- [ ] 音频单独输入路径可用，WAV/MP3/FLAC 解码、分离、转写、编排及来源链齐全。
- [ ] MIDI 可编辑并实际发声，参考分轨可独立试听；默认重建不叠加同一参考声部。
- [ ] 新 FLP 通过格式、引用、固定宿主重开、另存新副本和后台渲染验证。
- [ ] 固定 24 片段及 6 首真实歌曲的质量门槛、10 次稳定性及性能预算通过。
- [ ] 真实 MIDI 保真与未知字段的原有阻塞未被规避；音频推断与源事实明确区分。
- [ ] GUI 完整，取消／恢复／错误提示／预览和历史可用，无需命令行。
- [ ] 干净 Windows 安装版、许可与依赖清单、使用说明及发布证据齐全。
- [ ] 最终音乐试听验收通过，发布版本被明确标记；不以分轨回放冒充转写质量。
