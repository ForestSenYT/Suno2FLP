# MoE 模型程序 MIDI 候选

此开发接口把当前固定 [MoE 候选](YOURMT3_MOE.zh-CN.md)的全部推断音符导出为可编辑
MIDI 文件组。它与官方 MIDI 保真路径分开，不接通 GUI 作业、音源或 FLP 写入器。
`status=unqualified_candidate`、`writer_eligibility=blocked`、
`execution_allowed=false` 始终保留；文件正确不代表音乐准确或能够发声。

## 显式使用

```powershell
uv run suno2flp export-yourmt3-moe-midi <yourmt3-moe.json> --output <不存在的新目录>
uv run suno2flp verify-yourmt3-moe-midi <新目录/moe-midi.json>
```

仅接受原目录中完整的当前 MoE 生产记录，沿用其整数 WAV 解码范围；Single、旧源码
后端、未结束的生成流或压缩音频解码记录不能通过改标签升级。准备模型和推理是
独立步骤；导出会在新目录重新解码全部保留词元，核对 13 通道的合并前后事件、音符
和错误计数，不重新运行神经网络。每次校验保留新重放证据，不覆盖生产记录。

## 文件与时钟

- 每个非空 `(模型通道, 实际模型程序)` 单独一个 `notes/modelch-XX-program-YYY.mid`。
  不把同一模型通道的其他程序折叠为主程序，也不把超过 15 个旋律程序合到同一端口。
- 每份是 Type 1、两条轨：技术时钟及音符。独立文件旋律通道固定为 0，鼓固定为 9。
  模型地址不是源 MIDI 通道；模型标签不证明 GM、插件或音源可用。
- 模型程序 100 是 **Singing Voice**，不能解释为 GM100。文件不发程序切换、CC、
  弯音或拍号消息；原生音符动态另存，试听动态显式固定为 96。
- `960 PPQ / 500000 µs` 仅把音频秒换算为技术 tick，**不是估计的 120BPM 或 4/4**。
  原点不变；每个 binary64 起止秒坐标先精确转为有理微秒，再独立就近半向上取整。
  每个边界保留原 bits（含负零）、原有理时间、tick 和有符号误差，绝对误差至多
  `3125/12 µs`（约 0.260417ms）。不会把舍入后的坐标覆盖回原始音符。
- 所有 13 个地址、空地址、原音符顺序／索引、模型程序、原生动态和解码／合并错误
  保留在报告中；完整生产词元和事件经当前文件身份引用。音符不得超出原音频长度。
  正时长舍入坍缩、同键嵌套导致 FIFO 配对倒置、错误地址或超过 20000 音符均失败；
  不裁剪、平移、删音或截取前缀后冒充成功。空输入只得到明确未验收的空候选。

## 完整性和发布

`moe-midi.json` 保存完整来源快照、各文件身份、固定策略、时钟误差、后端、当前
应用／mido／解释器清单。独立检查器验证完整 SMF 头、轨长度、规范 VLQ、七位数据、
允许的消息、标签、结束位置及全部事件；重建每个源音符的确定顺序，不只比较总数。
旧四声部 MIDI 检查复用同一严格字节解析器，其配方明确增加该依赖，原有行为不放宽。

输出目录必须不存在、父目录已存在，不能与来源或后端重叠，拒绝链接／重解析路径。
说明文件先写，暂存报告后写；所有音符文件、完整目录清单、说明和当前来源证据通过
后，再次核对完整输出目录和文件语义，才独占原子发布完成文件。失败或取消保留新诊断，
不留下完成标记。后台词元
重放有原有 2700 秒进程界限；取消在受控边界检查，不承诺原生进程内即时取消。
完整报告上限 16MiB，每个 MIDI 上限 8MiB；预算不足明确失败，不删减证据。

重新验证必须使用当前原始来源、后端和代码；不能移动／改写清单来绕过身份。
入口先检查明显的目录冲突；最终仍保留运行时、原始文件、全部 payload 成员和哈希
复查。私有原曲、MIDI、后端、实验和真实报告均不进入 Git 或分发包。

MoE 的保留快照显式沿用已审计后端的 `30000` 文件／`4GiB` 边界；实际固定 payload
有 `22738` 个成员，高于通用快照默认的 `20000`。通用默认值保持不变，文件数和
字节上限按根分别冻结，调用方后续改动不能放宽它们；清单、字节及当前身份仍全部
复查，不按前缀截断。仅复核旧 payload 字节不授予旧后端当前源码或模型资格。

## 验证与剩余限制

默认测试使用原创小型音符和合成生产边界，不要求模型、DAW 或 GPU。设置
`SUNO2FLP_MOE_MIDI_PRODUCER` 后，可显式运行
`tests/integration/test_moe_midi_external.py`，对独立准备的当前生产记录执行真实词元
重放、文件导出及另一 MIDI 导入器的完整音符比较；缺少前提明确跳过。

本曲 MoE 听验仍为“尚未试听”，先前 Single 的否定反馈继续有效。模型、音乐、角色
音源路由、宿主／FLP、曲库、GUI 和安装发布门槛均未由此解除。不要把这些推断文件
自动喂给官方 MIDI 保真写入器；下一步需独立音乐及路由证据，完整目标仍按
[交付路线](DELIVERY_ROADMAP.zh-CN.md)推进。
