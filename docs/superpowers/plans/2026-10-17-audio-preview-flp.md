# Audio-inference FL26 candidate slice

Authoritative scope: the approved deliverable design and DELIVERY_ROADMAP.zh-CN.md.
This slice produces a real-song editable FLP/render candidate, not release qualification.
Execute inline, test-first; one fresh-context whole-branch review before integration.

1. Pin the separately observed exact-build reference components; reject different bytes.
   Preserve opaque records. Use the upstream-observed built-in sampler scope rule;
   do not import GPL implementation. Record the license/runtime assessment.
2. Derive explicit twelve-channel routing from the complete current estimated MIDI.
   Preserve every projected boundary/occurrence and its original provenance; drums
   select nine one-shot voices with an explicit root-key mapping. Technical 960 PPQ,
   120 BPM and declared note-offs remain approximations, not musical tempo evidence.
3. Original encoder and independent byte-budget verifier. Only assessed note, clip,
   channel selector/name/enable, cut-group, gain and sample-reference fields may change.
   Do not truncate active audio: retain source extent plus explicit tail padding.
4. Exclusive new bundle with original deterministic percussion samples, MIDI/source
   audit copy, identities and current-source validation before completion publication.
   Add thin CLI; retain old writer/strict MIDI/template gates. No default host invocation.
5. Synthetic mutation, timing, nine-route, provenance and output protection tests;
   required offline checks, package/installed smoke. Fixed-host background references
   and actual new-song rendering use owned process-tree bounds; no desktop input.
6. Update capabilities/limitations and primary-source notes. Push only public code,
   original tests and documentation. Exact-head independent review, current CI and
   latest-main checks precede matching-head squash merge.

Pre-flight: source MIDI export is immutable and path-bound; new files do not alter
its producer recipes. Its blocked legacy writer field is never promoted. A new
candidate-only export profile has no authority to qualify models/jobs/music/release.
Native evidence must cover this slice's actual fields; uncertainty remains a blocker.
The current real-song job continues once, without restart or serialized-trust shortcuts.
